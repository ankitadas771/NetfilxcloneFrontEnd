# Netflix Clone 2.0

A static HTML/CSS/JS Netflix clone deployable to GitHub Pages, Netlify, or any static host.

## Pages

| File | Description |
|---|---|
| `index.html` | Entry point — redirects to landing |
| `landing.html` | Marketing / sign-in page |
| `profies.htm` | "Who's Watching?" profile selector |
| `home.html` | Browse page with movie rows |
| `mylist.html` | My List page |
| `preview.html` | Full-screen video preview |

## Deploy

### GitHub Pages
Push to `main` — the included `.github/workflows/static.yml` handles deployment automatically.

### Netlify / Vercel
Drag-and-drop the project folder, or connect your repository. No build step required.

## Assets
All images and the `Intro-Netflix.mp4` file must remain in the **root** of the project (same folder as `index.html`).
